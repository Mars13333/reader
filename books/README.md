# 书籍工程与媒体示例策略

这个目录保留每本书的结构化制作工程，包括元数据、脚本、来源映射、视觉计划、口播时间轴、审稿记录和发布文案。

为控制开源仓库的克隆体积，`book-010-浮生六记` 是当前唯一保留完整媒体的端到端示例：

- `public/assets`：原创分镜、无字封面插画和 WAV 主音频；
- `output/final.mp4`：正式有声成片；
- `output/cover-3x4.png`、`output/cover-4x3.png`：两种发布封面。

`book-001`～`book-009` 只保留工程文本，大体积图片、WAV 和 MP4 不再放在当前版本中。旧书配置中的交付路径用于记录当时的生产契约；媒体缺失是开源归档策略，不代表当前检出版本能够直接通过这些旧书的交付文件验收。

以后由 `book:auto` 创建的新书仍会在本地生成正式媒体，但 `.gitignore` 默认不提交这些文件。只有明确选定新的完整示例后，才应同步修改忽略规则和本说明。
