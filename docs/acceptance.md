# 标准书单视频验收规则

- 画面：1080 × 1920，30 FPS，H.264；只保留重点大字，不烧录口播字幕，也不生成自制播放进度条。
- 时长：9 分 30 秒至 10 分 30 秒。
- 镜头：至少 45 个独立画面；单镜头约 10～15 秒，关键叙事变化必须有对应插画。
- 音频：成片固定封装刘飞男声 `zh_male_liufei_uranus_bigtts`，语速固定为 `-10`；WAV 主时钟只作为工程内部渲染素材，不单独交付 MP3。
- 内容：不得把小说虚构当成史实；必要边界在相关叙述中自然说明，不设置独立免责声明，也不出现长段原文朗读。
- 素材：只使用项目内原创插画，不使用原书封面或影视演员形象。
- 分镜比例：配置了 `portrait-2x2-9x16-v1` 的新书，每张 PNG 母图必须是纵向 9:16（允许 0.5% 像素取整误差），内部固定 2×2，四个子画面也各自为 9:16。正方形或其他比例必须在 TTS 和渲染前阻断；已发布的 `book-003` 不追溯修改。
- 亮度：从 `book-002` 开始，分镜与封面默认采用明亮日光或充足天光；主体肤色、衣纹和环境暗部必须可辨，不得以纯黑背景、重度暗角或压死阴影作为默认风格。
- 首帧：从 `book-003` 开始，第一张插画淡入前的画布必须为 `#000000`，不得再出现黄色或其他主题色空帧；该规则不改变后续插画的明亮标准。
- 开头：不自动叠加额外的 AI 画面提示标签。
- 进度条：视频画面不生成自制播放进度条，发布平台使用自己的播放进度控件。
- 安全区：顶部常驻标题使用当前书的 `content/video-layout.json`，纵向位置保持在 270～330px、左右边距保持在 96～160px并横向居中。`book-001`、`book-002` 保留原 32～40px 配置；从 `book-003` 开始为 42～48px，且始终小于章节重点字。章节重点大字的顶部保持在 460～560px，至少展示 6 秒，并按每字 0.30～0.50 秒计算阅读时间。两者都必须避开搜索页顶部搜索框。
- 对齐：音频真实采样数决定总时长，画面跟随口播章节边界重新分配。
- 字幕：Codex 工程不生成 SRT；把有声 MP4 导入剪映后，使用“识别字幕”根据最终音频生成精准字幕。
- 审批：分镜、插画、TTS 和渲染开始前，当前 `script.json` 的 SHA-256 必须与 `approval.json` 一致；脚本改动后必须重新审阅、重新批准。`book:auto` 只能免除人工等待，不能跳过哈希审批命令。
- 脚本自审：内部审稿归档前必须先通过 `npm run book:quality`。`source-map.json` 必须记录专名标准写法和 Codex 六项自审；自审哈希必须匹配当前脚本。用户默认无需逐字审稿。
- 脚本交接：分步模式下，Codex 自审通过后只向用户交接“审核通过，继续下一步就行”；用户以“脚本已批准，开始生成分镜、原创插画和两种发布封面”授权进入视觉生成。自动模式下，用户运行 `npm run book:auto` 已授权当前书完成本地视觉、TTS 与渲染，质量门通过后无需再次等待，但仍必须执行 `book:review`、`book:approve` 和 `book:approval-check`。
- 开场：第一句话直接进入冲突、反常识、代价或结果，钩子不晚于前 2 秒；不得先报书名、作者、栏目或“今天我们来讲”。前 10～20 秒必须兑现第一个事实、结论或证据，并引出下一问题。前两段不得使用独立“阅读边界”“小说不能当史书”等免责声明消耗留存；确有必要的史实边界应在相关叙述中最短说明。
- 持续留存：长视频约每 20～40 秒完成一次“小兑现＋新悬念”。`retentionPlan.segmentBeats` 与口播段落一一对应，每段明确兑现内容，除结尾外同时引出下一问题。
- 文案：Codex 必须逐句口播复审，不得把病句、生造口语、专名错字、重复表达或模板化段落留给人工逐字排查。
- 工程：当前书的 `content/visual-plan.json` 明确记录每个镜头；`npm run book:produce` 严格串联审批检查、素材预检、配音、排期、验收和渲染。
- 封面：从 `book-003` 开始，`output` 只交付 1080×1440（3:4）和 1440×1080（4:3）两种 PNG，不再生成 1080×1920（9:16）。两种比例分别排版；真实书名必须与 `book.json.title` 完全一致，并且是全封面最大、最醒目的文字。作者和 6～32 字推荐语只能作为次级信息；图片模型不得生成中文，封面文字统一由代码排版。前两本书的既有三封面配置与文件不追溯修改。
- 发布物料：`content/publish.json` 必须包含 6～30 字的发布标题和 1～2 句、每句 8～80 字的作品简介；`book:produce` 同步生成并验收 `output/publish-copy.txt`，固定追加 `#保持阅读 #书籍分享 #个人成长 #认知提升`，供上传时直接复制。
- 发布：抖音书单视频默认不添加章节信息；只有教程、课程等确有跳转需求的内容才单独启用。
- 结尾：新书不得使用“这里是十分钟读懂一本书”作为固定栏目口号；直接完成观点收束或自然进入互动问题。
